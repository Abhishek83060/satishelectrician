# Satish Electrician Website

## Before hosting
Open `index.html` and replace every:
- `+91XXXXXXXXXX` with Satish's real phone number
- `Your City & Nearby Areas` with the actual service area
- `Mon–Sun • 8:00 AM – 8:00 PM` with actual timings

The WhatsApp links automatically use the same number.

## Easy hosting
### Option 1: Netlify
1. Create a Netlify account.
2. Choose "Add new site" / deploy manually.
3. Upload this website folder (or the ZIP contents).
4. Netlify gives you a public `.netlify.app` website address.
5. You can later connect your own domain.

### Option 2: GitHub Pages
1. Create a GitHub account and a new public repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In repository Settings → Pages, enable deployment from the main branch.
4. GitHub will provide the website URL.

No database or server is required for this static website.
